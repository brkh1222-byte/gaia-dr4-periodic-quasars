# gaia-dr4-periodic-quasars

A pre-registered blind test: do published binary-black-hole ephemerides for periodic quasars predict Gaia DR4 (2014–2020) light curves better than red noise?

📄 **Read the research proposal:** [PROPOSAL.md](PROPOSAL.md) · **Tasks:** [TASKS.md](TASKS.md)

⏰ Pre-registration must be committed before Gaia DR4 is released (2 Dec 2026).

## Plan

Candidate ephemerides (CRTS/PTF/ZTF) → pre-Gaia DRW and sinusoid fits → **pre-registration commit** → Gaia DR4 epoch photometry → Bayes factors vs DRW null → RNAAS
